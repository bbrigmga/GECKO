What is Gecko PM?

Monthly portfolio research, automated end-to-end

Gecko PM (moon-machine-lite) is a FastAPI web app you run locally. Click Run Monthly Analysis and it orchestrates data collection, three Grok LLM calls per pipeline stage, and saves checkpointed results to disk.

Macro reportGrok synthesizes market news + Wikipedia + live web search into a 3-month economic outlook.
Firm scoringEvery S&P 500 company gets a 1–100 score and investment report from Grok.
Top 30Highest-scoring firms are ranked locally — no LLM call.
PortfolioGrok builds a 15-asset monthly allocation with weights, thesis, edge, and risk.

Tech stack

  • Backend: Python, FastAPI, asyncio pipeline
  • LLM: xAI Grok (or OpenRouter) via Responses API
  • UI: Static dashboard at localhost:8765 with SSE live progress
  • Storage: JSON checkpoints under runs/YYYY-MM/run_id/run.json

Checkpointing

After each major step, state is saved to runs/. Interrupted runs can resume — already-scored tickers are skipped.

The Three Grok Prompts

Verbatim white-paper exhibits in app/prompts.py

macro_prompt(context) Exhibit 2D 3-month US economic timeline + forecast tables. Uses live web search.
firm_prompt(company, industry, macro, financials, news) Exhibit 1 Investment report in third person + numeric score 1–100. One call per S&P 500 company.
allocation_prompt(top_reports) Exhibit 2E 15-asset monthly portfolio. May include stocks, ETFs, bonds, TIPS — not limited to top 30.

Score parsing

Grok's firm response is parsed for Score: X via regex. The score drives ranking; the full report text feeds the portfolio step.
